# Phone rehearsal checklist - judges' R5 release

Start with the [illustrated judges' guide](docs/Commute_Copilot_Judges_User_Guide.pdf) and [release record](docs/JUDGES_RELEASE.md). This checklist is for a human rehearsal on physical devices. Desktop mobile emulation has passed; physical-device results are **NOT TESTED** until someone records them below.

Use the public HTTPS [Commute Copilot](https://commute-copilot-nebula.simhongmen.chatgpt.site) in Safari on iPhone or Chrome on Android. No APK, app account or Home Screen install is required. Use a normal browser tab; private browsing may discard saved data.

- [ ] Open the link/QR on mobile data or Wi-Fi. The app opens without a hosting login.
- [ ] In Plan, select Tampines (EW2) and Bugis (EW12) from suggestions. Set Depart later, 21 September 2026, 10:00 SGT. Tap Find my route.
- [ ] The on-screen keyboard dismisses normally and does not trap the search/date/time controls. Read the route summary, tap Continue, then Start Journey.
- [ ] Current trip shows readable current/next instructions. Use Update my current step and I am here; verify a step changes only after confirmation.
- [ ] Switch views and reload. The accepted trip is retained. Pause/resume and simple-guidance changes preserve its progress.
- [ ] Show to staff shows a large relevant message. Changing its request does not advance the trip or contact anyone.
- [ ] Drag/tap the journey-panel handle; switch Map/Station guide. Map attribution remains visible; indoor limitations are clear. In Settings, choose Fewer transfers with a 15-minute extra-time allowance, then repeat with Haw Par Villa (CC26) to Aljunied (EW9), same date/time.
- [ ] Try bus-stop search and Bus stop details. Verify service numbers, stop code and directions are readable. Presence in the directory does not guarantee a timed route.
- [ ] Enlarge browser/system text and rotate the phone. Check the main actions and navigation remain reachable with browser chrome visible.
- [ ] Save a route and pin a commute. Reopening/checking it recalculates; it never silently starts a trip.
- [ ] In Spending, enter a clearly named sample charge and a weekly/monthly budget. Reload, then remove the sample if using a personal browser.
- [ ] While online with an accepted trip, use Check offline availability. Wait for readiness, then turn on airplane mode and reload. Confirm saved instructions/progress remain, with no claim of fresh arrivals or street maps.
- [ ] Reconnect and reload. Optional location is requested only when explicitly enabled; declining it leaves manual operation usable.

For this hosted release, live arrivals, street-address routing and caregiver sharing lack their server-side configuration. Do not treat their unavailable states as successful live-provider tests. Indoor directions and real step-free paths remain work in progress. Bus source validity ends 2 October 2026; rail source validity ends 31 December 2026, subject to calendars. Keep the fixed example date for later demonstrations.

Record failures with device/browser, step, visible message and a screenshot without personal information. Do not include API keys, private share links or personal location history.
